# 小说代理人（Novel Writing Agent）

完整规范见：`openspec/changes/novel-writing-agent/specs/novel-writing-agent/spec.md`。执行时以其中 **MUST** 为准；本节为操作清单。

## 何时使用

- 用户在仓库里**撰写 / 续写 / 改稿**小说章节（如 `极道天魔/`）。
- 用户提到**字数统计、长章节、恐怖升级、爽文、系统流**等。

## 硬性规则（摘要）

1. **简体中文正文**（除非用户明确要求其他语言）。
2. **长章节**：每章交付 **5000 字以上**（写入章末统计行**之前**测量）。
3. **章末一行统计**：在「本章完」或约定结束标记之后，**单独一行**  
   `（本章字数统计：XXXX 字）`  
   - 数字 **XXXX** = **不包含本统计行** 时，整文件字符串长度。  
   - 口径与 PowerShell 一致：`(Get-Content -LiteralPath <file> -Raw).Length` 对「不含统计行的正文」计算。
4. **题材**：恐怖/规则系升级 + **主角开挂爽感**（系统偏袒、破局、可见收益）；勿长期纯被动受虐。
5. **原创**：独立情节与设定；不因目录同名而仿写知名作品。
6. **仅改点名章节（硬约束，优先于任何润色欲）**  
   - 每次任务**只**动用户**明确指定**的章节：必须能对应到**单一路径**或**唯一章节号**（如「只改 `第002章-任务.md`」）。  
   - 用户说了「改稿 / 润色 / 修」但**没说哪一章** → **禁止改任何文件**；**先问**：要改哪一章（或是否授权批量范围）。  
   - **禁止**因「风格统一、顺便、其它章看起来 also、伏笔」**主动**改未点名章节。  
   - 仅当用户**原话**包含更大范围（如「`极道天魔` 下全部 md」「第1–3 章一起改」）时，才允许多文件编辑。  
   - 字数脚本、搜索工具同理：**一次只传用户点名的那个 `-Path`**，不擅自对整目录跑。
7. **恢复章节**：用户误删时恢复指定文件，并**重算**字数统计行。

## 章末统计模板

正文最后应为：

```markdown
（本章完）

（本章字数统计：5123 字）
```

其中 `5123` 替换为：把文件末尾上述**统计行整行删掉**后，剩余全文 `.Length` 的数值。

## PowerShell 校验示例

```powershell
$p = "极道天魔\第001章-灰门.md"   # 改为目标文件
$s = Get-Content -LiteralPath $p -Raw
# 手动去掉末尾「（本章字数统计：…）」一行后应得的字符数，与文中填写的数字一致
```

可使用仓库脚本（若已添加）：

```powershell
.\scripts\update-chapter-wordcount.ps1 -Path "极道天魔\第001章-灰门.md"
```

脚本会按**同一口径**重写末尾统计行（仅处理该文件）。
